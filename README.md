# AI-Powered Multi-Agent Disaster Response System

An interactive disaster-response decision-support and training simulator. The project models rescue agents coordinating in a changing disaster environment, with victim prioritization, resource-aware decisions, hazard-aware pathfinding, and dynamic replanning.

## Tech stack

- React + TypeScript
- Vite
- Three.js / React Three Fiber
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This repository contains a software simulation/prototype. It does not by itself represent a deployed physical drone or rescue-robot system.
